### 1.4 ⭐ 从作者自己的数据里**验证**出来的关键语义（这是本报告最硬的部分）

对 `lion_h.t` / `david_h.t` 的逐顶点属性做统计分析（20,874 顶点 / 97,131 四面体）：

* 属性 `weight` **精确等于** `(1/4)·Σ_{τ∋v_i} |τ|`，最大相对误差 **5.6e-8**。
  * 换成 `(1/5)·Σ|τ|` 偏 20%；换成 `Σ|τ|` 偏 300%。**所以质量就是重心对偶体积，不是外心 Voronoi 体积，也不是单四面体体积。**
  * 参考：该组 2D 代码同一条规则是 `ν_i = (1/3)Σ 相邻三角形面积`。
* 属性 `h` 是体积调和映射的像 ψ(v_i) ∈ B³：**100% 的 `boundary` 顶点满足 |h| = 1.000000（±1e-6）**，内部点 |h| ∈ [0.059, 0.9998]。
* 规模：`lion_h.t` 20,874 V / 97,131 T；`david_h.t` 19,984 V / 90,575 T；每顶点关联四面体数 min 5 / max 46 / mean 18.6。

⇒ **站点 = 网格顶点（不是四面体质心）**，`p_i = ψ(v_i)`；**质量 = ν_i = Σ_{τ∋v_i}|τ|/4**；Σν_i ≡ Vol(M)（恒等式）。源测度是 B³ 上的**连续 Lebesgue 测度**，内部会把 ν 重新缩放使 `Σν = Vol(clip domain)`。

## 3. 阶段 0：输入与预处理

### 3.1 对输入网格的要求

* **拓扑**：M 必须是拓扑 3-球（可定向、连通、边界是亏格 0 的闭曲面、无内部空腔）。有空洞/多连通需要先做分块或改用支持复杂拓扑的 measure-controllable 版本。
* **方向**：所有四面体 signed volume > 0。**这是必须做的归一化**，否则后面所有能量/雅可比符号都反。
* **质量**：sliver（最小二面角 < 5°）会直接导致阶段 1 折叠。建议先做 ODT/ODV 光滑或 Lloyd 松弛。

我为这一点付出了代价：一开始用「球面点 + 内部点做 Delaunay」造测试网格，得到

| 网格 | 顶点/四面体 | radius-ratio 均值 | 最小二面角 |
|---|---|---|---|
| 随机点 Delaunay 球 | 663 / 3790 | **45.3** | **0.46°**（37 个 sliver） |
| 立方球网格（cubed-sphere，n=6） | 343 / 1296 | 22.3 | 41.2°（无 sliver） |

前者的 sliver 使调和映射直接翻转 26–59 个四面体；换成结构化立方球网格后全部消失。**结论：输入质量不是可选项，是前置条件。**

### 3.2 TetGen 格式（已实测 round-trip 精确）

`.node`：
```
<#nodes> <dim=3> <#attr> <#markers>
<id> <x> <y> <z> [attr...] [marker...]
```
`.ele`：
```
<#tets> 4 <#attr>
<id> <n1> <n2> <n3> <n4> [attr...]
```
* id 必须连续（meshio 会因不连续报错）；只接受 4 节点四面体；marker 映射到 `point_data["tetgen:ref"]` / `cell_data["tetgen:ref"]`。
* meshio **不支持** `.face` / `.edge`，要自己解析。
* 代码：`TetMesh.from_tetgen` / `TetMesh.write_tetgen`（`src/tetparam/mesh.py`）。

### 3.3 质量度量（本仓库实现）

* `radius_ratio = R_circum / r_in`，正四面体 = 3，越大越差。
* 6 个二面角（用外向法向夹角计算，注意本仓库 `TET_FACES` 的定向表）。
* **翻转**：`signed_tet_volumes(dst) <= 0` 的个数。⚠️ 不要用 `|f(τ)|/|τ| < 0` 判翻转——源网格自身若有反四面体，这个比值也会是负的，会误报（我踩过）。

## 4. 阶段 1：三维共形（调和）映射 ψ : M → B³

### 4.1 数学

三维没有"共形"的严格离散类比（Riemann 映射定理在 3D 不成立），实践中的标准做法是**体积调和映射**：最小化 Dirichlet 能量

```
E_D(f) = Σ_{τ∈T} |τ| · ‖∇f‖²_τ  =  ½ trace(fᵀ L f)  =  ½ Σ_{s=1..3} f_sᵀ L f_s
L_ij   = Σ_τ |τ| ⟨∇λ_i, ∇λ_j⟩           （P1 有限元刚度矩阵）
```

在边界固定的约束下求解 `L_II f_I = −L_IB f_B`。

等价地，这是四面体 cotan 权重下的 Laplacian 系统，权重（参考文献 [5] 的原始定义）：

```
k_uv = (1/12) Σ_i l_i · cot θ_i          （i 遍历包含边 {u,v} 的四面体；
                                          l_i = 该四面体中 {u,v} 的**对边**长度，
                                          θ_i = 沿那条对边的二面角）
```

现代写法（Crane 等）：`w_ij = (1/6) Σ ℓ_kl cot θ_kl`。二者与 `|τ|⟨∇λ_i,∇λ_j⟩` 等价。

**⚠️ 实现陷阱（我踩到的）**：`∇λ_k` 是 `E⁻¹` 的**行**，不是列（`E = [v1−v0 | v2−v0 | v3−v0]`）。而且散列组装必须用
`rows = np.repeat(T, 4, axis=1).ravel()`、`cols = np.repeat(T, 4, axis=0).ravel()`；
用 `np.tile(T, (1, 4))` 会得到一个**静默错误**但 `K@1 == 0` 仍然成立的矩阵。

### 4.2 边界 ∂M → S²（决定成败的一步）

三条路线，按推荐度排列。**括号里是本仓库的实现状态，请务必看清——第 1 条是空的。**

1. **球面共形 / 球面 AEM**（质量最好）—— **❌ 本仓库未实现**
   * `github.com/garyptchoi/spherical-conformal-map`（MATLAB，开源）：`map = spherical_conformal_map(v, f)`，配套 `mobius_area_correction_spherical`。
   * `math.ntnu.edu.tw/~yueh/projects/SphereAEM/SAEM.zip`（MATLAB，核心函数是 P-code；**许可证：仅学术/研究，不可商用**）：`S = SphericalAEM(F, V)`，`S = RiemanianBijectiveCorrection(F, S)`。
   * **为什么空着**：Python 侧没有可用的现成实现——CGAL / libigl / MeshLab / pymeshlab / potpourri3d / gpytoolbox 经逐个 introspect 验证**都没有球面参数化**（pymeshlab 的 281 个 filter 里 `spher*` 只有"生成球体"），而上面两个都是 MATLAB。
2. **非线性热扩散**（论文参考文献 [39] 的原始做法）—— **⚠️ 本仓库只有简化版**
   * 原方法：对弦能量 `E = ½ Σ k_uv |f(u) − f(v)|²` 做最速下降，梯度取**切向**分量 `Δ_PL f − ⟨Δ_PL f, f⟩ f`，每步后归一化到 `|f| = 1`，再加 Möbius / 质心归一化。
   * 本仓库的简化版 = `harmonic.boundary_map_sphere(method="laplacian")`：同为"投影梯度 + 重投影"，但**用组合（均匀）权重而非弦能量的 cotan 权重**、**固定步数而非收敛判据**、**没有 Möbius / 质心归一化**、**没有双射性保障**。
3. **径向投影**（最简单，只在实体关于某点星形时正确）—— **✅ 已实现**
   * `harmonic.star_ball_map`：`y = x / R(θ,φ)`，`R` 为该方向射线到边界的第一交点距离（Möller–Trumbore，射线分块向量化）。对星形域是**构造性双射**。
   * `harmonic.boundary_map_sphere(method="radial")`：从质心径向投射到球面。

**为什么第 1 条空着不影响结论**：实测边界映射（radial / laplacian 两版）在可用形状上**边界折叠都是 0/320**；真正折叠的是**内部的调和延拓**（26–59 个 / 3790 个四面体，见 §4.3）。三维没有"调和映射到凸域必为同胚"的定理，**把边界换成完美的球面共形，内部照样折**。所以瓶颈在折叠修复和阶段 2，不在边界映射精度——球面共形只影响**畸变大小**（更好的初值 → OT 收敛更稳、残余更小），不影响**可行性**。

**要补的话，三条路**（按性价比）：
* **升级现有实现**（约 50 行，纯 Python）：把 `boundary_map_sphere` 的均匀权重换成弦能量的 cotan 权重，加收敛判据和 Möbius / 质心归一化。这是文献 [39] 那条路线本体。
* **复用 smartmesh 的 Ricci 流**：`smartmesh/riccimesh/schemes.py`（VertexScaling 离散共形度量）+ `flow.py`（Newton 求解器）改造成球面 Ricci 流（χ = 2，需要锥点方案）。这是两个项目之间唯一真正可复用的技术点。
* **离线外包**：MATLAB 工具箱跑一遍，导出球面顶点坐标，Python 侧读入。一次性、离线、不影响运行时依赖。

### 4.3 ⚠️ 三维调和映射不保证单射（实测数据）

这是文献里众所周知的坑，我实测确认（Delaunay 球网格，663v/3790t）：

| 形状 | 径向边界 + 调和延拓 | 翻转四面体 |
|---|---|---|
| 球 | 0 / 3790 | 边界折叠 0/320 |
| 梨形 pear(0.6) | **56 / 3790** | 边界折叠 0 |
| 扭转 twist(1.1) | **6 / 3790** | 0 |
| 鼓包 bump(0.30) | **30 / 3790** | 0 |
| 弯曲 bend(0.5) | **27 / 3790** | 0 |
| 锥形 taper(0.45) | 1 / 3790 | 0 |

**边界无折叠而内部折叠** ⇒ 问题出在调和延拓本身，不是边界映射。工程对策（本仓库实现）：

1. `star_ball_map`：星形域上的构造性双射初值（射线投射 + 径向缩放），保证 0 翻转。
2. `volume_penalty_relax`：折叠修复。最小化 **体积失配能量** `Φ(y) = Σ_τ (|τ_y|/|τ_0| − 1)²`，它对负体积也光滑有界，能把负体积拉回正目标。梯度用 `∂|τ|/∂v_k = (A_k/3) n_k = n_k/6`（`n_k` = 第 k 个顶点对面三角形的面积向量）。
3. `fold_free_relax`：在**正体积约束**下最小化 Dirichlet 能量（回溯线搜索），得到"调和但单射"的映射。
4. `ball_map(method="auto")`：依次尝试 star / harmonic，按 (翻转数, E_V 超界) 排序取最优，再按需松弛。

**更彻底的做法**（若你的形状超出星形域很多）：用 IEM/3DQC/3DDEQ 那类**带双射约束**的优化，或参考 2025 年新工作 `arXiv:2506.17025`（Lyu, Chen, Choi, Lui, "Volumetric Parameterization for 3-D Simply-Connected Manifolds"）§5.2 "Enforcing the bijectivity"。

## 5. 阶段 2（路线 A）：显式离散最优传输

### 5.1 问题设定（严格写清方向）

设 ψ: M → B³ 是阶段 1 的调和映射，把 M 的体积测度推前成 B³ 上的测度

```
μ := ψ_#(dV_M / Vol(M)),     μ|_{ψ(τ_i)} = |τ_i| / (Vol(M)·|ψ(τ_i)|) · dV
```

（ψ 是分片线性的，所以 `ψ(τ_i)` 是真正的四面体，μ 在每个 `ψ(τ_i)` 上是常密度。）

我们要的保体积参数化 `F : M → B³` 满足：对任意 A ⊂ M，`Vol(F(A)) / Vol(B) = Vol(A) / Vol(M)`。

**构造**：取 OMT 映射 `T : (B³, 均匀测度) → (B³, μ)`（Brenier，`T = ∇u`，u 凸），则

```
F = T ∘ ψ  （或等价的 F = φ⁻¹ ∘ ψ）
```

**离散化（论文用的就是这个）**：把 μ 近似成原子测度，站点取**网格顶点的像** `p_i = ψ(v_i)`，质量取**重心对偶体积** `ν_i = Σ_{τ∋v_i} |τ| / 4`（§1.4 已验证）。于是问题变成求 Laguerre（乘方图）权重 `h`，使

```
W_i(h) = { x ∈ B³ : |x − p_i|² − h_i  ≤  |x − p_j|² − h_j  ∀j }
|W_i(h)| = ν_i · |B| / Vol(M)
```

**复合**：逆传输映射 φ⁻¹ 把每个站点送到它自己的乘方单元，所以

```
F(v_i) = W_i(h) 的质量中心（volume centroid）
```

论文原文的表述就是 "the inverse map φ⁻¹ maps each ..."，2D 代码里第 5 步是 `maps each vertex v_i to the centroid of W_i(h)`，3D 发布版代码里是 `_power_cell_center`（快捷键 'm'）。本仓库实现为 `volume_ot.ot_vertex_map`。

> 注：摘要里的另一句措辞（"把推前体积测度搬到标准欧氏体积测度"）描述的是同一个映射的对偶视角；只有 `φ⁻¹∘ψ` 与记号、代码、数据三者一致。

### 5.2 对偶问题（凸、可解）

最大化（GLY 变分原理，参考文献 [29]）：

```
E(h) = Σ_i ν_i h_i − ∫_{B³} max_i ( |x − p_i|² − h_i ) dx        （凹函数）

∇E(h) = ( ν_i − |W_i(h)| )_i                    ← 就是"体积差向量"
Hessian:  a_ij = −|W_i ∩ W_j| / |p_i − p_j|     (i ≠ j)
          a_ii = −Σ_{j≠i} a_ij
```

以 ρ ≡ 1 时 `a_ij = −(两单元共享面的面积)/|p_i − p_j|`。2D 特例是 `∂w_i/∂h_j = −|e_ij|/|ē_ij|`（幂图棱长 / 对偶幂 Delaunay 棱长）。

**牛顿方向**：`Λ := −H` 是正半定的加权图 Laplacian（对角 = Σ 权重，非对角 = −权重），
`h ← h + Λ⁺ ∇E`，其中 `Λ⁺` 取最小范数解（`scipy.sparse.linalg.lsqr`），因为常数向量在核里（所有权重加同一个常数不改变幂图）。

> 我做了有限差分验证：`∂|W_i|/∂h_j` 与 `Λ` 的相关系数 **−1.000000**，最大误差 4.6e-9 级别。公式无误。

### 5.3 3D 幂 cell 体积怎么算

三条路，按工程量排序：

1. **提升到 4D 凸包**（Lévy 2015 / Caplan IMR 2021）：
   `z_i = (y_iᵀ, sqrt(max(w) − w_i))ᵀ ∈ R⁴`，域坐标补 0，则 `P_i(Y,w) = V_i(Z)`。
   幂图 = 提升点集的 Voronoi 图。**伪代码（Caplan Algorithm 3，capacity-constrained Voronoi = 半离散 OT）**：
   ```
   ν_t = m_t / N
   repeat:
       lift  z_i = (y_i, sqrt(max(w) − w_i))
       Vor(Z) ∩ Ω                      # 用现成 4D 凸包/正则三角剖分
       energy, mass = Σ ...
       dE/dw       = ν − mass
       w = L-BFGS(w, dE/dw)
   ```
2. **重入式半空间裁剪**（Lévy 2015 Algorithm 2，即 geogram 的做法）：沿四面体×单元对传播，用 `clip_by_plane` 逐个半空间裁凸多面体，最后四面体扇形分解求体积。**这是能 scale 的做法。**
3. **直接调 `scipy.spatial.HalfspaceIntersection` + `ConvexHull`**（我的实现）：每个 cell 一次线性规划求内点 + qhull 求顶点 + qhull 求体积。

### 5.4 ⚠️ 三个必须知道的数值陷阱（我实测踩到的）

**陷阱 1：空 power cell 会让对偶无上界。**
如果某个 cell 变空，`Σ ν_i h_i` 里的 `ν_i h_i` 项可以无限增大，而积分项不变——于是"最大化对偶"这件事本身失去意义，任何只看对偶值的线搜索都会**主动接受**这种退化解。
**对策（geogram 也是这么做的）**：线搜索候选必须满足 `n_empty == 0` 才允许接受；否则 `λ ← λ/2` 回退。geogram 的 `optimize_full_Newton` 更狠：一旦出现空 cell 直接 `FATAL error, exiting Newton` 返回。
我加上这条之前，求解器会在几十次迭代里反复"改善对偶"却把质量误差从 0.7 推到 63.6；加上之后同一算例 6 次迭代收敛到 5.7e-12。

**陷阱 2：步长钳制。**
站点在一次牛顿步里移动太远会改变幂图拓扑。标准做法是钳制 `|Δh_i| ≤ c·d_min²`（`d_min` 是最近邻站距）。我第一版把"间距"错误地取成了"第 1 与第 2 近邻距离之差"，得到比正确值小 57 倍的步长，求解器每步只降低 1.7% 误差。改成 `(4·median(最近邻距离))²` 后正常。

**陷阱 3：站点在球面上（边界顶点 |p_i| = 1）时数值脆弱。**
边界顶点的 cell 是贴着球面的薄壳，容易在牛顿步里被挤空。这就是陷阱 1 的主要触发源。**对策**：多层初始化（先解一个粗站点子集，再细化），这是 geogram 的 `optimize_levels` 的用途；论文的 `-threshold` 默认只要求 **1e-4**，不是 1e-9。

### 5.5 我的实现现状（诚实汇报）

`src/tetparam/laguerre.py` 是**验证正确的核心**，但**不是生产级求解器**：

## 6. 阶段 2'（路线 B）：等价变分形式 —— 体积拉伸能量最小化

### 6.1 为什么两条路是同一件事

* 半离散 OT 的对偶（§5.2）本身就是"容量约束 Voronoi / 乘方图"的变分问题（Aurenhammer 定理：给定单元体积的幂图唯一，且使 `∫|x − T(x)|²` 最小）。
* 更直接的桥梁：**Galilée / Alliez 2005 的变分四面体网格化**。Alliez 等人（ACM TOG 24(3) 617-625, 2005，DOI 10.1145/1073204.1073238）原文说 `E_CVT` 的最小化 = "minimizing the volume between a paraboloid and an underlaid, circumscribing piecewise linear approximant formed by planar patches tangent to the paraboloid"——**这就是 L² 半离散 OT 的 Kantorovich 对偶**。而且同一篇文章明确指出：**`E_CVT` 在三维会大量产生 sliver**，所以他们改用 `E_ODT`（把下包络换成上包络）。
* 另一条桥梁：Lévy 2015 §1.5 明确说 Gu–Luo–Sun–Yau 的离散 Monge–Ampère 变分原理与半离散 OT **是同一个变分原理**（`φ(y_i) = ½w_i`，`ψ(x) = ½ inf_i(‖x−y_i‖² − w_i)` 就是 power cell）。

### 6.2 体积拉伸能量与下界定理

```
E_V(f) = Σ_{τ} |f(τ)|² / |τ|        （|f(τ)| 取**带符号**体积）
```

**下界定理**（Yueh et al.；Huang et al.；n-VSE 推广到 n 维）：

```
E_V(f)  ≥  V(f)² / V(M),      等号成立 ⟺ 所有 r_τ = |f(τ)|/|τ| 相同 ⟺ f 保体积
```

其中 `V(f) = Σ_τ |f(τ)|`。

**关键工程事实**：只要边界顶点钉在单位球面上且映射不折叠，像区域就是边界像所围的多面体球，其体积是**常数** ⇒ `V(f)` 自动固定 ⇒ 最小化 `E_V` 就是把所有 `r_τ` 拉向同一个常数。**这就是为什么"最小化体积拉伸能量"能替代显式 OT。**

（文献里有两种归一化，等价：本文的 `E_V = Σ|f(τ)|²/|τ|`，与修改 cotan 权重形式 `E_V = ½ trace(fᵀL_V(f)f)`，`L_V` 的每个四面体权重取 `|f(τ)|` 而非 `|τ|`。本仓库两种都实现了：`metrics.stretch_energy` 与 `volume_ot.stiffness_stretch_energy`。⚠️ 注意 `arXiv:2210.09654` 的公式 (2.4)/(3-3) 与 (8.1) 相差一个整体符号，要选一种并写单元测试锁定。）

### 6.3 算法

**VSEM（固定边界）** —— 我实测最稳的一条：

```
E_V 的梯度： ∂E_V/∂y_i = Σ_{τ∋i} 2(|τ_y|/|τ_0|) · (对面面积向量 n_k / 6)
约束：边界顶点固定在单位球面上
求解：L-BFGS-B（scipy.optimize.minimize, jac=True）
       可选折叠罚： + λ · Σ max(0, −r_τ)²
```

**IEM（边界在球面上滑动）** —— `arXiv:2407.19272`：

```
交替执行
  (a) 固定边界解内部（VSEM）
  (b) 边界做球面上的投影梯度步：
        y_b ← y_b − α · (I − y_b y_bᵀ) ∇E_V ,  然后重投影到 |y_b| = 1
```

我实现了 IEM（`volume_ot.iem` / `boundary_relax_sphere`）。**我的实测结论（可能出乎意料）：在我这几个算例上 IEM 相对 VSEM 基本没有改善，在 taper 上甚至更差**（`E_V` 超界 1.30% → 3.85%）。原因是固定边界造成的"不可达下界"在我的算例里不是主要误差来源，而边界滑动步长/停止条件没有调好。**所以：先用 VSEM，IEM 作为可选精修。**（原论文是在更难的算例上报告 IEM 优于 VSEM，我用的是中等变形算例。）

**n-VSE / VSEM 的固定点迭代**（论文原始做法，每次一个稀疏线性解）：

```
E_V(f) = ½ trace(fᵀ L_V(f) f),   L_V 用修改 cotan 权重（每四面体权重 = |f(τ)|）
临界点方程： L_V(f) f = 0 （边界条件固定）
迭代：  给定 f^k 组装 L_V(f^k)，解 L_V(f^k) f^{k+1} = 0
```

等价地，本仓库用 `fem_stiffness(mesh, weights=|f(τ)|)` 组装，这是同一件事的直接实现。

## 7. 阶段 3：四面体剖分 / 重网格化

### 7.1 逆映射 f⁻¹ 的廉价求值

`f : M → B³` 是分片线性双射，所以 `f⁻¹` 也是分片线性的：

```
给定球内查询点 q：
  1. 在**像网格** f(M) 的四面体质心上建 KD-tree，取 candidates=48 个候选
  2. 对每个候选做重心坐标测试
       λ_k(x) = δ_{k0} + ∇λ_k · (x − v_0)        ← 注意 δ_{k0} 项，漏了会全错
      接受 λ ∈ [−tol, 1+tol]，tol = 1e-6（球面量级）
  3. 原像 = Σ_k λ_k · v_k   （v_k 是**原始**网格顶点）
```

* 落在像区域之外的查询点（球面附近，因为两个球面多面体的三角剖分不同）投到**最近的边界三角形**上，再取原像——这是数学上正确的边界原像（`_project_to_boundary` / `_closest_point_on_triangle`）。
* 复杂度约 O(log m) + O(candidates) 每次求值。

### 7.2 三条重网格化 Recipe

| | **Recipe A：球内采样 + 原 ∂M 重新剖分** ⭐ | **Recipe B：模板拉回** | **Recipe C：体 r-自适应** |
|---|---|---|---|
| 边界共形 | ✅ 天然（原边界是硬约束） | ✅（模板保留像边界） | ⚠️ 需锁边界 |
| 实现难度 | 低 | **极低** | 高 |
| 3D 验证 | ✅（本机 TetGen/Gmsh 实测） | ✅（本仓库实测） | ❌ 论文只做了 2D |
| 度量精确控制 | 近似 | 近似 | ✅ 1e-8 |
| 能否改单元数 | ✅ | ✅ | ❌ |
| 计算量 | 分钟 | 秒 | 分钟~小时 |

#### Recipe A（推荐）

**核心思想：不要在球里做网格再拉回来；在球里只做点采样，把采样点作为 Steiner 点、连同原始 ∂M 三角面片一起交给成熟的 mesher。**
这样"边界兼容、sliver、sharp feature"三个难题全部变成 mesher 的责任。

```
1. 在球内按 r_k = R · (k/N)^{1/3} 分层采样（**必须**：按 r 等距分层会让球心过密，
   体积偏差 ∝ r²，保体积的收益直接丢掉）
2. 用 f⁻¹ 把采样点拉回 M（用 §7.1，或更便宜地用 OT cell 质量中心）
3. 以「原始 ∂M 三角面片 + 这些内部点」为输入，调 fTetWild 或 TetGen
```

#### Recipe B（模板拉回，本仓库实现，秒级）

```
新网格 = f⁻¹(球内模板网格)        # 共用模板的连接关系
```

* 优点：**连接关系直接复用 ⇒ 天然 conforming、单元数可控、不需要 mesher、边界自动兼容**。
* **模板选择的实测结论**（这是关键）：

| 模板 | 顶点/四面体 | 定位成功率 | 体积误差 | 翻转 |
|---|---|---|---|---|
| `refine(像网格, 1)`（质心细分） | 1639 / 5184 | **1639/1639** | **0（机器精度）** | 0（球/梨/锥），8（弯曲） |
| `uniform_ball_template`（均匀点 + 像边界顶点 Delaunay） | 718 / 3821 | 714/718 | −1.37e-2 | 0–17 |
| 独立立方球模板（边界三角剖分不同） | 343 / 1296 | 217/343 | −2.9e-1 | 372 |

⇒ **只有当模板的边界曲面与像网格的边界曲面一致时，拉回才精确。** 均匀模板需要把半径缩到 0.995 才不掉点，代价是 1.4% 的体积损失。所以工程上：**要均匀/自适应就用 Recipe A，要快/精确就用 Recipe B 的 `refine` 模板。**

#### Recipe C（尺寸场搬回 M）

球内给一个尺寸场 `h_B`，则 M 上的等效尺寸由换元公式给出：

```
h_M(x) = h_B(f(x)) · |det Df(x)|^{1/3}
```

对保体积映射 `|det Df| ≡ const`，所以球内均匀尺寸 ⇒ M 上均匀尺寸。**（此式我标为 [未验证]：需要合成算例校验。）**

### 7.3 六个必须事先想清楚的失效模式

| 编号 | 失效模式 | 对策 |
|---|---|---|
| F1 | 映射只**近似**保体积 ⇒ 尺寸场与质量解耦 | 报告归一化后的比值分布；或改成 Recipe C 显式补偿 |
| F2 | 逆映射求值贵 | 用 OT cell 质量中心做 O(1) 近似；或 KD-tree 缓存 |
| F3 | 边界不兼容（模板边界 ≠ 像边界） | **永远以原始 ∂M 为硬约束**（Recipe A），或只拉回边界一致的模板（Recipe B/refine） |
| F4 | sliver | 用 `E_ODT`（不是 `E_CVT`）；Delaunay refinement |
| F5 | sharp feature 丢失 | polyline feature + jittering；不要让参数化重采样尖角 |
| F6 | OT 奇异集撕裂 | 自适应加密奇异集 |

## 8. 验收指标

定义（本仓库 `metrics.distortion_report` 全部实现）：

| 指标 | 公式 | 通过线（建议） |
|---|---|---|
| 体积比 `r_τ` | `|f(τ)| / |τ|` | 归一化后 `max|r/mean − 1| < 0.05` |
| 体积畸变 | `max(r, 1/r) − 1`（归一化后） | 均值 < 0.05，p99 < 0.15 |
| 雅可比行列式场 | `det Df`（= 带符号体积比） | 全部 > 0；**并且报告 `frac(J<0.5)`** |
| 体积拉伸能量 | `E_V = Σ|f(τ)|²/|τ|` | 超界（`E_V/(V(f)²/V(M)) − 1`）< 2% |
| 等体积能量 | `E_I = V(e)/V(f)·E_V − V(f)` | → 0 |
| 双射性 | 翻转数 + `frac(J<0.5)` | 翻转 0；**"无翻转" ≠ "映射好"**（实测有 16.5% 的 J<0.5 却 0 翻转） |
| 逆映射一致性 | `f⁻¹(f(v)) − v` 的最大偏差 | < 1e-10（模板与像网格一致时应为 0） |
| 重网格化体积 | `Vol(M')/Vol(M) − 1` | < 1% |
| 单元质量 | radius-ratio、最小二面角 | 最小二面角 ≥ 10°（工程目标） |

**独立验收（最重要的一条）**：不要只看 OT 求解器自己的收敛判据（梯度范数/质量误差），**要看复合之后的 `|det J|` 分布**。要求 `max |log det J| < 0.05`。

## 10. 选型建议（一句话版）

1. **只想要能跑、能出结果**：阶段 1 的边界用 `boundary_map_sphere(method="laplacian")`（本仓库已实现，**是文献 [39] 非线性热扩散的简化版，不是严格共形**；追求更低畸变可离线用 `garyptchoi/spherical-conformal-map`（MATLAB）算好球面坐标再导入），内部用调和延拓（本仓库已实现），阶段 2 用 **VSEM**（本仓库已实现，L-BFGS，秒级），阶段 3 用 **Recipe A**（球内 `r^{1/3}` 分层采样 → 逆映射 → fTetWild）。
2. **要论文原汁原味的 OT 复合**：阶段 2 换成 **geogram + exploragram** 的 `OptimalTransportMap3d`（BSD-3，多层初始化 + BRIO），站点 = 顶点、质量 = `Σ|τ|/4`，`F(v_i) = W_i` 质量中心。我提供的 `laguerre.py` 可以拿来对照验证/做小规模实验。
3. **要度量控制（自适应/用户指定密度）**：用 measure-controllable 那篇的思路——OT 目标测度换成用户指定的 ν，然后用 Recipe A/B 重采样。
4. **闭源商用**：只在 **BSD-3**（geogram/exploragram、Eigen）、**MPL-2.0**（fTetWild）、**LGPL**（Mmg）里选。**避开** TetGen ≥1.5（AGPL）、CGAL Mesh_3（GPL）、TetWild 原版（GPL）、PyMesh（仓库里根本没有 LICENSE 文件）。

### 10.1 与 2026 年 SOTA 的差距（按优先级排列的改造路线）

本仓库的阶段 2 是 2016/2017 年那套做法。2026 年有两篇工作正好补在我们的短板上，都已核实存在。

**① 求解器：换成预条件非线性共轭梯度（最高优先级）**

Liu, Huang, Lin, Yueh, *Volume-Preserving Parameterizations via Preconditioned Nonlinear Conjugate Gradient Method*, **JOTA 2026**, DOI [10.1007/s10957-026-03002-5](https://doi.org/10.1007/s10957-026-03002-5)，即 [arXiv:2407.19272v2](https://arxiv.org/abs/2407.19272v2)（v1 就是本文档 §6.3 引用的那篇 *Isovolumetric Energy Minimization…*）。

* 与我们的关系：**等体积能量 `E_I`、球面边界优化、以及"应该优于 VSEM"的判断，我们都已经实现/验证过**（`volume_ot.iem`、`boundary_relax_sphere`、`metrics.isovolumetric_energy`）。
* 我们缺的正是它的核心贡献：**预条件子 + 强 Wolfe 线搜索的 NCG**，以及由此得到的全局收敛性。我实现的是"边界投影梯度 + 内部 L-BFGS"，实测**没有跑赢 VSEM**（pear 1.362%→1.399%、taper 1.304%→**3.847%**、bent 1.669%→1.645%、bump 2.393%→2.345%）。这个负面结果与该论文的卖点并不矛盾——**差距在求解器，不在能量**。
* 改造动作：把 `iem()` 的优化器替换为论文的预条件 NCG（预条件子取 `E_V` 的近似 Hessian，线搜索用 strong Wolfe），并补上单元折叠的几何校正。

**② 目标域与自适应：放开"必须映到单位球"这个硬编码（次高优先级）**

Lyu, Chen, Lui, Choi, *Adaptive Volumetric Parameterization of Simply Connected 3-Manifolds with Applications*, [arXiv:2608.08672](https://arxiv.org/abs/2608.08672)（cs.GR，v2 2026-08）。同一组的前作是本文档附录引用的 [arXiv:2506.17025](https://arxiv.org/abs/2506.17025)。

它给出的三种递进目标域设置，正好对应我们的三个已知缺陷：

| 论文的能力 | 我们的现状 | 后果 |
|---|---|---|
| 指定实心**椭球**目标域 | 硬编码单位球 | 细长实体的球面映射畸变天然大 |
| **半径可变的自适应椭球**（体积归一化） | 无 | §6.4 实测残余 1.3%–2.4% 消不掉，根因就是"边界被冻结、目标域不能动" |
| **海嵌入式自由边界域** | 只有"边界在球面上滑动"（IEM） | 自由度不够 |
| **密度均衡**（3D 密度均衡映射，扩散式） | 只有"体积均匀"，**没有用户指定密度** | 文档里承诺的"度量可控"并未实现 |
| 显式**去折叠几何校正** | 自研 `volume_penalty_relax` + `fold_free_relax` | 有效但无理论保证 |
| 多分辨率 / **局部自适应体网格重剖** | §7.2 的 Recipe C，标为 **[未验证]** | 恰好是论文的应用之一 |

* 注意它走的是 **3D 拟共形 + 密度均衡映射（DEM，扩散式）**，不是我们的乘方图 / OT 路线——是一条更便宜、且天然支持自由边界的替代实现路径。
* 改造动作：把 `ball_domain` / `vsem` 里的单位球换成参数化椭球（三个半轴作为额外优化变量），并加一个扩散式密度均衡步。

**③ 两篇共同的前提，也是我们共同的边界**

两篇都明确限定 **simply connected 3-manifolds**。所以带 38 个把手的车轮对它们**同样无解**——这不是本仓库实现的局限，而是这一类方法的问题边界。车轮要做参数化，只能走"分块"或"切孔 + seam 约束"，那属于另一个课题。
